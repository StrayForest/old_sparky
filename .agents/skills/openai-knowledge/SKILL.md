# OpenAI Knowledge

Use official OpenAI sources before advising or editing OpenAI-related behavior.

## Workflow

- Prefer MCP server `openaiDeveloperDocs`.
- If MCP is unavailable, use only `developers.openai.com` or `platform.openai.com`.
- Do not rely on memory for model names, parameters, pricing, availability, or Codex config keys.
- Keep changes narrow unless the user asks for a migration.

Name the source checked, the decision made, changed files, and any fallback used.
