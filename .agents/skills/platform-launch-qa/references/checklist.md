# MVP Launch QA Checklist

- Register/login/logout and session persistence.
- Edit profile Deadlock card, hero pool, roles, and dream-team slots.
- Create a private tournament and verify auto invite code.
- Claim invite code from the Tournaments hub.
- Join tournament from current profile data and respect rank/capacity limits.
- Organizer sees separated tournament view and organizer panel.
- Run ready-check and reconcile withdrawn/disqualified participants.
- Run captain round and participant responses.
- Generate auto-assignment, detect stale runs, publish and lock roster.
- Seed opening round from locked roster, report matches, progress bracket, complete tournament.
- Admin grants public-create permission, moderates participants, and performs audited status/visibility overrides.
- Check invite-only visibility from anonymous, participant, organizer, and admin perspectives.
- Check desktop and mobile layout for core screens.
